# TRASSA V4.9 – Marktplatz-Details, Angebot & Nachricht

Neu:
- Offene Anfragen im Marktplatz sind anklickbar.
- Klick öffnet die echte Anfrage-Detailansicht aus PostgreSQL.
- Fremde offene Anfragen zeigen ein Formular zum Angebot abgeben.
- Preis, Gültigkeit, Ansprechpartner und Konditionen werden gespeichert.
- Anbieter können direkt aus der Anfrage eine Nachricht an den Auftraggeber senden.
- Gespräche können nun auch vom Anbieter aus einer offenen Anfrage gestartet werden.
